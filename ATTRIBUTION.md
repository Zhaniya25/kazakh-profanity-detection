# Dataset Attribution and License

## Original Dataset

This project uses a manually selected subset of the KazSAnDRA review dataset.

Original dataset authors: Rustem Yeshpanov and Huseyin Atakan Varol.

Sources:
- Project page: https://issai.nu.edu.kz/kazsandra/
- Repository: https://github.com/IS2AI/KazSAnDRA
- Research paper: https://aclanthology.org/2024.lrec-main.844/

## License and redistribution

The dataset source materials should be checked against the license and redistribution terms stated by the official KazSAnDRA repository and project page before redistributing review text. The license of a research paper must not be assumed to apply automatically to the dataset files.

License reference to verify: https://creativecommons.org/licenses/by/4.0/

## Project modifications

This project selected a subset of review texts, applied preprocessing, and manually assigned binary profanity labels. The original sentiment labels were not used as profanity labels. The resulting annotations and trained classifier are independent academic contributions and are not official KazSAnDRA annotations.

The project does not imply endorsement by the original dataset authors.
